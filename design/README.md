# Zippest — Android App Design

一个参考 ZArchiver / RAR for Android 操作习惯的 Android 解压工具原型，由 Open Design 项目 `decompress` 生成。

## 主文件

| 文件 | 说明 |
| --- | --- |
| `decompress-app.html` | 主原型。打开即进入「内部存储」根目录，桌面 393 × 852 居中，手机全屏 |
| `screens/` | 真机尺寸截图（786 × 1704，2x） |
| `brand-spec.md` | 色彩、字体、圆角、间距规范 |
| `archive-v1/` | 第一版六宫格展示画板，仅作留档 |
| `archive-v2/` | 消费者式首页版本，仅作留档 |
| `archive-v3/` | Download 子目录起步的文件浏览器版本，仅作留档 |

## 信息架构（对齐 ZArchiver / RAR）

- 打开即「内部存储」根目录，不做欢迎页
- 顶部：左箭头返回键 + 当前目录 + 存储容量 + 新建 / 搜索 / 排序 / 更多（无单独路径栏）
- 根目录：Android、DCIM、Download、Documents、Movies、Music、Pictures、微信、腾讯等 14 个系统目录
- 文件列表：扁平样式、无卡片、文件夹优先、1px 分隔线
- 长按文件进入多选；选中后才显示勾选框与「已选 N 项」，底栏同时出现
- 全选为与文件行一致的勾选框
- 再次点击全选只清空选择，仍保持选择模式
- 支持左右边缘横滑返回、底部上滑回到目录首页
- 图片、GIF、视频使用缩略图；视频带播放角标，GIF 带 GIF 标记
- 包内浏览：压缩包内部路径与文件列表
- 底部工具条：选中项目后才出现，提供 解压 / 复制 / 移动 / 删除 / 更多
- 储存空间条固定在文件列表底部，选中后自动让位给底部工具条
- 解压设置：密码、目标位置（当前文件夹 / 新建同名文件夹 / 选择其他位置）、同名策略、编码
- 新建同名文件夹的位置为压缩包所在目录
- 自定义位置可在内部存储、SD 卡、OTG 中浏览任意文件夹
- 解压完成后会在目标目录生成同名文件夹与示例内容
- 文件夹选择器支持返回上一级；Esc 在子目录先返回上一级，到根目录后关闭
- 剪贴板图标与上次复制内容同行，右侧展开箭头，展开后可填入密码
- 同时解压多个压缩包时可勾选“使用相同密码”，复用同一个密码
- 复制/移动同样使用全手机文件夹选择器，并阻止移动到自身内部
- 任务抽屉：进度、速度、剩余时间、暂停/继续

## 已实现的交互

- 目录逐级进入与返回，顶栏同步显示当前目录
- 顶栏下拉提供目录首页、下载、相册、文档、微信快捷位置
- 当前目录搜索、名称/大小/日期排序
- 长按进入多选，选中后才显示复选框与底部工具条
- 打开压缩包并浏览包内目录
- 普通包与加密包解压，密码错误态
- 4 秒进度、完成状态、任务抽屉暂停/继续
- 设置页与深色模式切换

## 设计基线

- 画板：393 × 852 dp，Android 状态栏 + 手势条，安全区适配
- Material 3 组件与线性 SVG 图标，触摸目标 ≥ 48 dp
- 背景 `#F6F7F5`，卡片 `#FFFFFF`，主色 `#0F6B4F`，警示色 `#C4622D`
- 圆角 16–24 dp，版心 20 dp
- 字体：Noto Sans SC / Roboto

## 目录约定

- `design/`：设计稿、截图、品牌规范
- `android/`：预留给后续 Android Studio 工程（Jetpack Compose）

## Android 交接

当前 HTML 是交互原型，以下部分需要在 Android 端替换为真实实现：

- 文件系统：SAF / MediaStore，不要依赖固定路径
- 解压引擎：libarchive / 7-Zip / UnRAR，且禁止创建 RAR
- 安全：Zip Slip、Zip Bomb、符号链接逃逸、文件名编码与磁盘空间检查
- 后台任务：WorkManager 或前台服务 + 通知
- 剪贴板：ClipboardManager；Open Design 预览环境禁止网页读取系统剪贴板
- 分享与压缩包测试：系统 Share、真实完整性测试
- 文件操作、解压内容与任务进度目前在原型中为内存模拟

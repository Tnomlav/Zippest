# Zippest 1.22.0

这一版主要把「发布前检查」做成一条命令、补上离线可看的许可证，并修了两个解压相关的问题。

## 新增

- **关于页可以离线查看许可证全文**：以前「查看项目许可证」要打开浏览器，断网就只能看到一个打不开的页面；现在关于页多了「离线查看许可证全文」，许可证原文随安装包一起提供。

## 改进

- **修复 GBK 文件名压缩包解压后乱码**：包内预览能自动识别 GBK，但解压仍按 UTF-8 写文件名，结果中文名变成 `�`；现在解压沿用预览的判断，不用再手动切「文件名编码」。
- **存储空间不足时给出中文提示**：以前 TAR 系列解压到一半没空间会显示英文 `write failed: ENOSPC`；现在统一显示「存储空间不足。清理一些文件，或换到空间更大的位置（比如 SD 卡）再解压。」
- 发布前的 20 项检查现在由 `tools/preflight.sh` 一次跑完：版本号与 tag、versionCode 递增、lint、单元测试、ABI、16 KB 对齐、签名、权限清单、网络调用面、SHA256SUMS、链接可达性、发布说明齐全度。CI 在打 tag 时执行同一套检查，失败就不发布。
- `SHA256SUMS` 现在包含 `.aab`。1.21.x 的本地归档脚本通配符漏掉了 AAB，和 CI 产物清单不一致。
- 发版必须有面向用户的发布说明（`docs/release-notes/<版本>.md`）；缺失时 CI 直接拒绝发布，不再自动生成 commit 列表。

## 说明

- 没有新增权限；网络调用仍然只出现在「点版本号检查更新」。
- 覆盖安装即可升级，签名与 1.21.x 一致。

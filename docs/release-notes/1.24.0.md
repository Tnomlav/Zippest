# Zippest 1.24.0

这一版把解压和重命名的几个别扭点一次改掉了。

## 新增

- **菜单里可以直接预览压缩包**：选中单个压缩包后，底部「菜单」里多了「预览」，不用先进解压面板。
- **多包密码自动复用**：一次解压多个加密包时默认全部使用同一个密码；只有某个包的密码不同，才会在解压中途弹出「需要密码」，显示压缩包名称，补填后单独继续。

## 改进

- **重命名和文件名输入框加了 ×**：有选中就只删选中段（后缀默认是选中的），没选中才清空整行。
- **返回会回到原来的滚动位置**：文件列表和包内预览都按目录记住滚动位置，不再回到顶部。
- **点压缩包直接进解压面板**：只有右侧的进入箭头才打开包内预览。
- **多选解压后自动退出多选**，不再停在选择态。
- **分卷多选自动去重**：同时选了第一分卷和同名后续分卷时，只按第一分卷解压，避免「缺少第一卷」的困惑。

## 说明

- 输入法自己的剪贴板历史读取不到（Android 不提供公开接口），密码框仍使用系统剪贴板 + 输入法自带粘贴。
- 没有新增权限；覆盖安装即可升级。

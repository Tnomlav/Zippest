# Zippest 1.25.0

这一版按第八章的视觉清单收口：对比度、动效、选择态和提示位置。

## 改进

- **对比度**：浅色下错误色改为 `#A24617`（6.1:1），组件描边改为 `#7D8C82`（3.5:1），勾选框、输入框边框和删除文字都达到 WCAG；深色描边同步提亮。
- **预览页去掉无限呼吸光**：改成静态 1dp 主色描边，不再持续重绘，也不和「省电工具」的气质打架。
- **选择模式工具栏新增「解压」**：右下角悬浮按钮移除，一屏只留一个主动作，不再和工具栏重复。
- **Snackbar 移到手势条上方**：左对齐、最多两行，不再悬浮在列表中间挡内容。
- **「取消任务」热区**从 34dp 补到 48dp，符合触控最小尺寸。

## 说明

- 没有新增权限，行为逻辑不变，纯视觉与交互调整。
- 覆盖安装即可升级。

# Zippest 1.25.1

第八章 8.1 的收尾：把 Material 角色补齐，并给「界面里不许写死颜色」加了门禁。

## 改进

- **补齐缺失的 Material 角色**：`inverseSurface` / `inverseOnSurface` / `inversePrimary`、`scrim`、`surfaceTint`、`surfaceDim` / `surfaceBright`、`errorContainer` / `onErrorContainer` 现在都显式声明，不再落回 Material 基线。Snackbar 的反色底、弹层遮罩和高度染色从此受主题控制，换强调色也会跟着走。
- **门禁拦截硬编码颜色**：`tools/preflight.sh` 新增两项检查——`ui/` 下出现 `Color(0x` 直接失败（只允许 `theme/`），以及上述角色缺一个就失败。
- `design/tokens.md` 同步更新 error / outline 新色值和新增角色。

## 说明

- 纯颜色 token 调整，没有行为变化，也没有新增权限。
- 覆盖安装即可升级。

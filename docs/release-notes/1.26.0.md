# Zippest 1.26.0

第八章 8.3 与 8.4：把圆角/间距收进 token，给文件补上类型图标和空态插画。

## 新增

- **文件类型图标**：压缩包、图片、视频、音频、文档、代码、APK 各有自己的图标和语义底色，文件列表与包内列表都能一眼分清；压缩包不再和普通文件长得一样。
- **空态插画**：空文件夹、空回收站、无后台任务各有一张单色线性插画，替换原来的单个图标。

## 改进

- 圆角全部走 `ZippestRadius`：界面里不再有 `RoundedCornerShape(数字)`，10/14/18/22/99 统一到 8/12/16/24/胶囊。
- 间距统一 4 的倍数：2/6/10/14/18/22/26/30 归到 4/8/12/16/20/24/28/32；删掉 2dp 间距 token。
- 包内列表行高从 60dp 对齐到 64dp。
- 发布门禁新增两项：界面里出现圆角数字字面量、或 padding/spacedBy/Spacer 出现奇数 dp，直接失败。

## 说明

- 纯视觉调整，没有行为变化，也没有新增权限。
- 覆盖安装即可升级。

# Zippest 1.27.0

第八章 8.6 的三态模板，以及 8.2 / 8.4 / 8.5 的收尾。

## 新增

- **加载骨架**：文件列表、包内目录、任务中心在首次读取时显示灰条骨架，300ms 内读完就不闪一下，不再只给一个转圈。
- **统一错误页**：标题 + 人话原因（长异常折叠进「查看详情」）+ 重试 + 次出口（如「重新选择文件夹」）。
- **空态统一位置**：空文件夹、空回收站、空包、空任务都锚在可视区约 30% 处，不再随内容高度跳。

## 改进

- **减少动态效果**：系统动画缩放为 0 时，列表增删直接切换，不做过渡。
- **数字等宽**：13 档字阶全部启用 `tnum`，文件大小、进度、倒计时刷新时不左右跳。
- **图标尺寸归一**：行图标 24dp、内联 20dp，去掉 17/19/21/22/23 这几种散落尺寸。

## 说明

- 纯视觉与动效调整，没有行为变化，也没有新增权限。
- 覆盖安装即可升级。

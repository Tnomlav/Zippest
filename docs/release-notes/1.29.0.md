# Zippest 1.29.0

文件名与搜索先做好「跨文字」：中文、日文、变音拉丁与 RTL 文件名都能正确比较、排序、搜索和解压。界面语言仍是中文。

## 改进

- **文件名归一化**：统一按 NFC 比较文件名。macOS / 网盘传来的组合写法 `café` 和本机的预组合 `café` 不再被当成两个名字；重命名、解压重名去重都按同一规则。
- **按语言排序**：文件列表改用系统语言的排序规则，中文按拼音、英文不区分大小写，混排更稳定。排序结果与旧版可能不同，属于预期变化。
- **长文件名截断**：超长名称按完整字符截断，emoji 不会再被截成半个；压缩时生成的包名同样处理。
- **方向控制符清洗**：解压落盘的文件名和压缩包名会去掉 U+202A–202E、U+2066–2069 等 bidi 控制符，避免 `evil\u202Etxt.exe` 这类文件名伪装扩展名。
- **Shift-JIS**：文件名编码新增 Shift-JIS，日文 ZIP 可以直接选对编码。
- **乱码误判修复**：只有出现替换符 U+FFFD 或「锟斤拷」才判定为乱码；合法出现 `Ã`、`Ð`、`â€` 的葡语 / 冰岛语等 UTF-8 文件名不再被误改。
- **搜索忽略变音符号**：`cafe` 能命中 `café`，`uber` 能命中 `Über`；大小写与 NFC/NFD 写法差异都不影响，中文搜索不变。
- **中文逻辑去耦**：密码错误、分卷缺失等判断改为按错误类型，不再匹配界面文案里的中文关键字。这是内部整理，提示文案和操作结果不变。

## 说明

- 阿拉伯语、希伯来语文件名在列表里最多显示两行，避免单行省略号把 `.txt` 之类的后缀吞掉。

- 界面语言仍为中文；英文界面与文案抽取在后续版本。
- 排序、乱码判定与文件名清洗只影响新的显示与解压，已解压的旧文件不动。
- 无新增权限；覆盖安装即可升级。

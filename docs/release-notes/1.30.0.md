# Zippest 1.30.0

批量复制、移动和删除更快了，尤其是很多小文件的文件夹。

## 改进

- **本地复制改用 FileChannel**：同盘复制走零拷贝通道，失败时自动回退到 256 KB 缓冲；比原来的 8 KB 逐块复制少很多系统调用。
- **目录复制并行**：一个文件夹里的子项按 4 路并发复制，几百个小文件不再一个一个排队。
- **批量传输并行**：直接存储模式下，多选复制 / 移动按 3 路并发处理；SAF 模式保持串行，避免和系统文件提供程序抢锁。
- **批量删除并行**：多选删除（含移入回收站）按 4 路并发执行。
- 复制缓冲区从 64 KB 提到 256 KB。

## 实测

300 个 64 KB 文件（约 19 MB）：顺序复制 267 ms，4 路并发 168 ms，约快 37%（缓存目录，文件系统缓存已热）。

## 说明

- 同卷移动仍然走 `renameTo`，本来就是瞬时，不受影响。
- 没有新增权限；覆盖安装即可升级。

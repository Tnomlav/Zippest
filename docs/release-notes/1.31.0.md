# Zippest 1.31.0

这一版把中英文资源的底座搭好：默认资源改成英文，中文放进 `values-zh`，设置里新增语言切换。界面文案仍是中文，完整英文要等后续版本逐屏抽取。

## 改进

- **默认资源改为英文**：`res/values/strings.xml` 现在是英文（`Zippest`、`Open with Zippest`），中文放到 `res/values-zh/strings.xml`。中文系统显示中文，英文和其他语言显示英文。
- **设置里新增语言切换**：设置 → 外观 → 语言，可选「跟随系统 / 中文 / English」。切换后界面会重建；Android 13 及以上同时写入系统的「按应用设置语言」，与系统设置保持一致。
- **翻译缺键会被拦截**：`MissingTranslation`、`ExtraTranslation` 在 lint 里是 error，英文缺键（或中文缺译）都会让 CI 的 `lintDebug` 失败，避免发出半中半英的包。
- **伪语言只用于开发**：debug 包会生成 `en-XA` 伪语言（把英文拉长并加特殊字符），用来提前发现按钮和顶栏截断；release 包不包含，也不影响正常使用。

## 说明

- **界面文案仍是中文**：这一版只搭资源骨架和语言入口，除应用名、「用 Zippest 打开」外，设置、文件浏览、解压等界面还没有抽取翻译。选 English 后这些界面仍显示中文，属于预期，P2 会按屏幕分批补英文。
- **语言切换需要真机手动确认**：发布前的自动化操作中手机被切到其他应用，为避免打扰没有强制抢前台，三态切换、返回栈、未保存输入和系统语言同步还没有在真机上点过。请在设置里手动切换一次确认；如果切换后界面没有刷新，重启应用即可。
- 没有新增权限；覆盖安装即可升级。

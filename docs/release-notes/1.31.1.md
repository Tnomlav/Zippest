# Zippest 1.31.1

9.4 的验证补强，没有界面变化。

## 改进

- **语言资源验证**：新增真机测试，分别断言 English / 中文 / 跟随系统三种设置下 `open_with_zippest` 用的语言正确；不启动 Activity，避免测试卡在界面启动。
- **中文文案预算门禁**：发布检查新增一项，`ui/` 目录里的中文硬编码数量超过预算（当前 701）就失败；每抽完一批文案，把预算下调。
- 语言切换的公共逻辑抽到 `LanguageContext`，`MainActivity` 只负责读取设置并应用。

## 说明

- 界面文案仍是中文，英文抽取在后续版本。
- 设置里的「语言」手动点选与系统设置同步，仍需真机人工确认一次。
- 无新增权限；覆盖安装即可升级。

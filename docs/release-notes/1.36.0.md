# Zippest 1.36.0

文件浏览主屏与列表的英文抽取，文件浏览这一批基本收口。

## 改进

- 主屏提示、权限/位置错误、复制移动进度与结果（含「正在移动 N 项」「已复制 N 项」「N 项失败」）进资源。
- 列表行：已选中/未选中、预览压缩包、解压某某、文件夹；顶栏：返回、搜索、新建文件夹、更多。
- 左侧导航：位置、内部存储、子文件夹。
- `ui/` 中文硬编码从 430 降到 397。

# Zippest 1.37.0

这一版把预览、信息、快捷位置、压缩面板、任务中心、回收站、打开方式等页面一起抽成了资源。

## 改进

- 预览/信息面板：名称、大小、时间、类型、路径、条目数等。
- 快捷位置：标题、空态、外部存储、用量文案。
- 压缩面板 38 条：格式、级别、排除规则、密码、分卷说明与体积预估。
- 任务中心 40+ 条：状态、进度、暂停/继续/取消、速度与剩余时间（秒/分/小时）。
- 回收站 23 条：容量、清空、恢复、永久删除与确认句。
- 打开方式、快捷位置编辑、反馈、崩溃/密码弹窗、顶栏与选择工具条、任务行等。
- `ui/` 中文硬编码从 397 降到 153。

## 说明

- 解压面板（ArchiveScreen）、关于页正文、错误/通知仍是中文，最后一批处理。
- 本版未做真机验证。
- 无新增权限；覆盖安装即可升级。

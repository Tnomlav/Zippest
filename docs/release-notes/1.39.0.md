# Zippest 1.39.0

修复「打开方式」列表不全，并重做选择弹窗。

## 修复

- 旧实现查询应用时带了 `MATCH_DEFAULT_ONLY`，只返回**默认处理者**，很多注册了 VIEW / SEND 的应用被过滤掉，看起来像没有可用方式。
- 现在查询 VIEW、EDIT、SEND 三类动作，不再限制默认处理者，去重后全部列出。
- 分享类应用（ACTION_SEND）固定归入「分享」分组，不再依赖应用名关键字。

## 弹窗重做

- 列表高度从 320dp 提到 420dp，分组标题显示数量（「直接打开 · N」「分享或发送 · N」）。
- 每行增加动作副标题（打开 / 编辑 / 分享），选中态更清楚。
- 没有可用应用时显示空态，并禁用「打开」按钮。

## 说明

- 本版未做真机验证；打开方式列表需要下一步在真机上点一次确认。
- 解压面板（ArchiveScreen）的英文抽取仍未完成。
- 无新增权限；覆盖安装即可升级。

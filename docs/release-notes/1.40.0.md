# Zippest 1.40.0

修复「打开方式」列表偏少（1.39.0 的修复没有真正生效）。

## 修复

- 查询去掉 `MATCH_DEFAULT_ONLY`：之前只返回默认处理者，很多注册了 VIEW 的应用被过滤。
- 分享查询改用真正的 `ACTION_SEND` + `EXTRA_STREAM` + ClipData：之前 SEND 只带 data，几乎所有分享目标都匹配不到。
- 现在同时查询 VIEW / EDIT / SEND，按组件 + 动作去重，分享类固定归入「分享」分组。

## 验证

- 新增仪器测试 `OpenWithQueryTest`：对 `text/plain` 断言至少有一个 VIEW 目标、且必须包含 SEND 目标，真机通过。

## 说明

- 1.39.0 的提交只改了弹窗，没有把查询改动带进去，所以看起来“没变”；1.40.0 已修正并加测试。
- 无新增权限；覆盖安装即可升级。

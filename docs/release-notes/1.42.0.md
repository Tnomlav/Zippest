# Zippest 1.42.0

解压面板与包内预览完成英文抽取，界面文案的资源化到这里收口。

## 改进

- 解压面板：目标位置、同名文件、文件名编码、密码、分卷、体积提示、进度与结果全部进资源。
- 包内预览：顶栏、搜索、编码切换、空态、读取进度、多选与解压操作、密码弹窗（含「第 N/M 个」）。
- 解压相关错误（不支持格式、无法读取、测试失败、重命名失败）进资源。
- `ui/` 中文硬编码从 129 降到 28（剩余是「打开方式」分类关键字，不是界面文案）。

## 说明

- 下一版处理错误/通知的 data、service 文案，然后做英文审校与真机逐屏回归。
- 无新增权限；覆盖安装即可升级。

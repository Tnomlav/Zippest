# Zippest 1.43.0

错误提示与通知文案完成英文抽取，第九章的文案资源化到此结束。

## 改进

- 解压错误映射（密码错误、损坏、空间不足、缺分卷、文件不存在、不支持、无权限、超限、RAR5）改为资源，按错误类型取文案，不再硬编码中文。
- `archiveMessage()` 改为接收 Context；错误类型判断抽成 `archiveErrorKind()`，便于单测。
- 通知标题（解压/压缩的完成、失败、取消）与通知频道名称、描述改为资源。

## 说明

- 界面与通知文案已全部资源化；`ui/` 剩余 28 条是「打开方式」分类关键字，不是文案。
- 下一版做英文审校、`en-XA` 截断检查与真机逐屏回归。
- 无新增权限；覆盖安装即可升级。

# Zippest 1.44.0

修复切换语言后闪退回首页。

## 修复

- Android 13+ 设置 `LocaleManager.applicationLocales` 时系统会自己重建 Activity；代码里随后又调了一次 `recreate()`，两次重建撞车导致崩溃/闪回首页。
- 现在 13+ 只交给系统重建；13 以下才手动 `recreate()`，并加上 `isFinishing / isDestroyed` 保护。
- `attachBaseContext` 读取语言偏好加了容错，异常时回退到跟随系统。

## 排查

- 全仓库只有这一处 `recreate()`；其它语言相关逻辑（打开方式分类）已在 1.40.0 改为固定关键字，不随语言变化。
- 真机验证：中文 → English → 确定，页面重建后停在设置页，无崩溃；`dumpsys activity exit-info` 无新的崩溃记录。

## 说明

- 无新增权限；覆盖安装即可升级。

# Zippest 1.45.0

英文审校与 200% 字号回归，第九章收尾。

## 修复

- **200% 字号**：文件页底部存储条改为上下两行，右侧「所有文件访问已授权」不再被挤成每行一个字母。
- 选择工具条、解压操作条、解压面板拖拽行的高度从固定 64dp 改为最小 64dp，可随字号增长。
- 文件行的日期/大小说明允许两行，200% 下不再出现「Sep 29, 2…」。

## 审校与验证

- `en-XA` 伪语言：首启页整页可滚动、无重叠、无截断；按钮文字完整。
- 英文界面：文件列表、设置、快捷位置、解压面板、打开方式（系统 chooser）、存储条、日期格式均已核对。
- TalkBack 文案：英文界面下 content-desc 仅剩用户自己的文件夹名含中文，其余均为英文。
- 已知限制：`1 items` 这类英文复数暂未改 `<plurals>`，留给下一版；超长文件名仍以省略号截断。

- 无新增权限；覆盖安装即可升级。

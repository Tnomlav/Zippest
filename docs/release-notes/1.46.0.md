# Zippest 1.46.0

界面一致性：弹窗底色、按钮、主题色与底部存储条。

## 改进

- **弹窗统一白底**：对话框不再用带绿色调的 surfaceContainerHigh 与主题色染色，统一纯白、无高度染色。
- **按钮统一**：删除确认、回收站清空/永久删除改为同一套按钮组件——取消在左（文字按钮、灰字），确认在右（主色/错误色填充、48dp 高）。
- **主题色更鲜明**：森林绿、海蓝、紫罗兰、琥珀、玫瑰提高饱和度，容器色同步调整；石墨保持中性。
- **底部存储条**：去掉「所有文件访问已授权/只访问已授权目录」文字，只保留用量与进度条。

## 说明

- 其余弹窗已继承白底与 Material 默认的「取消左、确认右」布局，按钮组件正在逐步替换为同一套。
- 无新增权限；覆盖安装即可升级。

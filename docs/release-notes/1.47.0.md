# Zippest 1.47.0

后台任务弹窗改成和回收站一致的底部弹层，并继续统一弹窗按钮。

## 改进

- **后台任务**：从居中 AlertDialog 改为 ModalBottomSheet，标题栏 + 关闭按钮 + 列表 + 底部操作，和回收站一致；占用 88% 屏高，可滚动。
- 后台任务的「取消全部」使用统一的删除按钮（红底），关闭使用统一的文字按钮。
- 快捷位置删除弹窗的取消/删除按钮改用统一组件。
- 英文用词继续按惯例收紧（Open / Share / Extract / Compress / No matches / Not now 等）。
- 顶栏「更多」菜单顺序改为：排序 → 回收站 → 后台任务 → 设置（设置放最后）。
- 排序选项改为：名称 → 日期 → 大小 → 类型；同名文件策略改为：重命名 → 跳过 → 覆盖（破坏性选项靠后）。

## 说明

- 其余弹窗底色已统一白；按钮迁移仍在继续（密码、编码、快捷位置编辑等）。
- 英文复数（1 items）尚未改 plurals。
- 无新增权限；覆盖安装即可升级。

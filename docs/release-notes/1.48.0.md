# Zippest 1.48.0

英文复数修正，存储栏再压扁一点。

## 改进

- 数量文案改用 Android `<plurals>`：`1 item` / `2 items`、`1 record` / `2 records`、`1 selected` / `2 selected`，中文仍用「项 / 条」。
- 覆盖：信息面板条目数、任务中心进行中/已结束/历史数量、顶栏已选数量、删除确认数量、解压所选数量。
- 底部存储栏垂直内边距 8→4dp、进度条 5→4dp，整体更扁。

## 说明

- 密码、编码、快捷位置编辑等弹窗的按钮仍在迁移到统一组件。
- 无新增权限；覆盖安装即可升级。

# Zippest 1.50.0

收尾：深色强调色复核、200% 字号标题、折叠屏说明。

## 改进

- **深色强调色复核**：六种强调色在深色背景上的对比度为 8.9–11.3:1，全部远超 AA；浅色下只有琥珀 4.46:1 略低于 4.5，已调到 `#B45309`（5.02:1）。
- **200% 字号标题**：顶栏文件夹标题在放大字号时改用 `titleSmall` 并允许两行，不再出现省略号截断；正常字号保持 `titleMedium`。
- **折叠屏**：布局按 600/840dp 窗口宽度分栏，不使用 hinge 坐标；没有折叠屏设备可验证，保留为已知限制（不影响普通手机/平板）。

## 说明

- 无新增权限；覆盖安装即可升级。

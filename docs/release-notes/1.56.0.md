# Zippest 1.56.0

修复数量文案导致的崩溃。

## 根因

1.48.0 引入的 `<plurals>` 占位符写成了 `%1`（缺少 `$d`）。Android 把它当成 `%1 ` 格式说明符，`getQuantityString` 直接抛 `UnknownFormatConversionException: Conversion = ' '`，在任务中心、信息面板、顶栏已选等显示数量时崩溃。

## 修复

- 英文 7 组复数改为 `%1$d` / `%1$s` / `%2$d`；
- 中文 7 组同步改为 `%1$d`；
- 已用真机确认打开后台任务、选中文件、信息面板不再崩溃。

## 说明

- 1.48.0–1.55.0 都受影响，建议升级到本版。
- 无新增权限；覆盖安装即可升级。

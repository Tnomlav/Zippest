# Zippest 1.57.1

修复两处占位符导致的启动崩溃。

## 修复

- 1.57.0 新增的文件夹数量文案把占位符写成了 `%1`，`getQuantityString` 在首页渲染时崩溃；改为 `%1$d`。
- 任务剩余时间 `about_eta` 同样把 `%1` 当占位符（值为字符串），显示 ETA 时会崩；改为 `%1$s`。

## 防回归

- `tools/preflight.sh` 新增第 20 项：扫描两份 `strings.xml`，发现 `%1` 这类缺 `$` 的占位符直接失败。
- 文件夹行现在显示「N 个文件 · 时间」，只统计直接子文件，不含子文件夹。

## 说明

- 无新增权限；覆盖安装即可升级。

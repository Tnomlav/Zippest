# Zippest 1.59.0

修复中文密码的 AES ZIP 被误报「密码错误」。

## 根因

zip4j 在 AES 解密时用 **ISO-8859-1** 把密码字符转成字节（`AesCipherUtil.derivePasswordBasedKey` → `PBKDF2Parameters("HmacSHA1", "ISO-8859-1", ...)`）。中文密码会被替换成 `?`，PBKDF2 派生出的 key 与 ZArchiver/WinZip 用 UTF-8 得到的不一致，于是正确密码也校验失败。

## 修复

- 打开加密 ZIP 时依次尝试：原密码 → UTF-8 字节按 ISO-8859-1 重新解释 → GBK 字节按 ISO-8859-1 重新解释；用第一个能通过 AES 密码校验的。
- 校验只读取 16 字节，不影响解压速度；失败时仍报「密码错误」。

## 说明

- 你那个 `琪.zip` 用 ZArchiver 能打开，本版应该也能；请在手机上重新解压一次确认。
- 无新增权限；覆盖安装即可升级。

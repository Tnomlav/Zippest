# Zippest 术语表

界面文案的统一说法。改文案前先查这张表；新增概念先在这里登记，再进代码。
和 i18n 的关系见指南 §9：将来翻译时，这张表就是译名表的来源。

## 核心术语

| 概念 | 统一用词 | 不要用 | 说明 |
|---|---|---|---|
| 把压缩包里的文件取出来 | **解压** | 提取、解压缩、释放、unzip | 动词；按钮写「解压」「解压所选 N」 |
| 把文件打包 | **压缩** | 打包、压包、zip 一下 | 动词；按钮写「压缩」 |
| 压缩后的文件 | **压缩包** | 压缩文件、档案、archive | 名词；面板标题、错误提示统一用它 |
| 被切成几份的压缩包 | **分卷** | 分片、分割包、part | 首次出现补一句：`.001 / .002 这类被切开的包` |
| 目标目录里已有同名条目 | **遇到同名文件** | 重名文件、冲突 | 选项固定为：覆盖 / 跳过 / 自动重命名 |
| 包内文件名的字符集 | **文件名编码** | 字符集、charset、乱码修复 | 选项：自动 / GBK / UTF-8 |
| 删除后的暂存区 | **回收站** | 垃圾箱、废纸篓 | 恢复、永久删除、保留期 |
| 后台任务列表 | **任务中心** | 任务列表、队列页 | 进行中 / 已结束 / 历史 |
| 首屏的固定入口区 | **快速访问** | 快捷入口、收藏、常用 | 区块名；单个入口叫「快捷位置」 |
| 单个固定下来的目录 | **快捷位置** | 收藏夹、书签 | 仅指快速访问里的一个条目 |
| 解压/压缩的去向 | **解压位置** / **保存到** | 输出目录、目标路径 | 设置里叫「默认解压设置」 |
| 包损坏时的动作 | **修复** | 修补、恢复压缩包 | 只重建 ZIP 中央目录，别承诺“修复任意损坏” |

## 写法约定

1. **按钮用动词短语**：「解压」「开始压缩」「选择其他位置」，不要「确定」「好的」这种无信息量的词（危险操作按钮除外）。
2. **错误提示给下一步**：先说发生了什么，再说怎么办。例：「密码不对，检查一下大小写或换一个密码」。
3. **数字与单位**：文件大小用系统 `Formatter`（自动跟随语言），时间用相对时间（`DateUtils`）；不要手写 “MB” 或千分位。
4. **不要出现竞品名**，也不要出现“本应用”“该软件”这类第三人称，直接说「Zippest」或省略主语。
5. **首字母/中英混排**：中文句子里的英文缩写前后不加空格（`ZIP 包` 例外，保留空格可读性更好）；专有名词保持官方写法：ZIP、7Z、RAR、TAR、GBK、UTF-8、AES-256。

## 已做的统一（2026-11-09）

- `压缩文件` → `压缩包`：压缩面板标题、压缩引擎的 3 条错误提示
- `同名文件` → `遇到同名文件`：解压面板与设置项标题
- `重命名` → `自动重命名`：同名策略选项（避免和顶栏的“批量重命名”混淆）
- `分卷大小` 下补了解释：分卷 = 把大包切成 `.001 / .002…`，解压时打开第一个

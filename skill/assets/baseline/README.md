# 结构基准图

四张 SVG，画的是**骨架与参数**，不是像素稿。用途：

1. 让"同系列"有可并排的参照，而不是只靠文字想象。
2. 校准行高、栏宽、面板高度这类比例关系。
3. 给评审一个共同看的东西（对着图说，比对着形容词说有效）。

| 文件 | 画面 | 主要校验 |
|---|---|---|
| `01-list.svg` | 列表页 | 顶栏同底色、10 行 × 64、语义色方底图标、底部状态条 |
| `02-selection.svg` | 选择态 | 顶栏切换、复选框 48 热区、选中行浅绿、操作条 6 项 |
| `03-wide.svg` | 840dp 三栏 | 240 导航 + 内容 + 320 第三栏、分隔线通高 |
| `04-sheet.svg` | 底部面板 | 88% 高、28 顶角、字段组、sticky 主按钮 |

## 注意

- 图里的文字与图标是示意，不代表最终文案或图标库。
- 颜色取的是 `assets/tokens.json` 的浅色默认值；深色请按 `references/02-color.md` 自行替换。
- 不要把 SVG 当截图用：它没有状态栏适配、没有系统字体回退、没有 200% 字号验证。
- 修改任何 token 后，这四张图也要跟着改，否则它们会变成"看起来对、量起来错"的假基准。

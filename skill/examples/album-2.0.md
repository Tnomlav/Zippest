# 换皮推演：把 Zippest 语言套到 Album 2.0（相册 App）

这份示例证明一件事：**换的是语言，不是功能。** 相册该有的网格、时间线、清理、幻灯片都保留；
变的是壳、密度、颜色和动作顺序。

## 0. 先看现状（Album 2.0 的 token）

| 项 | 现状 | 与 Zippest 的差距 |
|---|---|---|
| 主色 | 荧光绿 `#00E673` | 太亮，作为"行动色"会刺眼；大面积出现时像社交产品 |
| 页面底 | 纯白 `#FFFFFF` | 少了"纸"的退后感，卡片只能靠阴影 |
| 强调色 | 6 套高饱和（蓝 / 青 / 橙 / 珊瑚 / 紫） | 不是"同一系列的不同配色"，是六种气质 |
| 页边距 | 7dp | 太贴边，密集网格可以，表单不行 |
| 圆角 | 8dp 一档 | 缺层级：卡片、面板、对话框用同一个角 |
| 字号 | 12 种（17/16/15/13/12/11…） | 没有字阶层级，靠"差 1sp"区分 |
| 类型图标 | 少 | 相册里没有"类型"概念，但有"分组 / 人物 / 地点 / 视频" |

**结论**：方向已经对了（深色底 + 绿色 + 扁平），缺的是"角色化"和"层级刻度"。

## 1. 三条不能照搬

照搬会毁掉相册的用法，所以这三条要改写：

1. **列表 vs 网格**：相册主视图必须是网格。规则改成"网格是内容，壳是列表语法"——顶栏、分区、选中、面板、设置全部照 Zippest；网格本身只借用它的间距 / 圆角 / 选中态。
2. **文件类型色**：相册不按扩展名分类，改成按"集合类型"：人物、地点、视频、收藏、截图。仍然只用 4 组语义色，不新增彩虹。
3. **"打开即内容"**：相册首屏是时间线（内容），不是相册列表。相册列表降为第二入口，放顶栏下拉或左导航。

## 2. token 对照（要改的六个值）

| Token | 现状 | 目标 | 影响 |
|---|---|---|---|
| `background` | `#FFFFFF` | `#F6F7F5` | 页面立刻"退后"，白色卡片浮起来 |
| `surface` | `#FFFFFF` | `#FFFFFF` | 不变 |
| `primary` | `#00E673` | `#0F6B4F` | 从"荧光"变"森林"，白字可读 |
| `primaryContainer` | 无 | `#D9F2E7` | 选中行、选中格子、当前导航 |
| `muted` | `#717975` | `#59625D` | 正文对白 6.31:1 |
| `PagePadding` | 7dp | 网格 4 / 页面 20 | 网格更紧，表单松开 |

强调色保留 6 个选项，但换成 `02-color.md` 里的 6 组深色版本；
"活力橙 / 珊瑚红"这类名字可以保留，色值必须换。

## 3. 三屏推演

### A. 时间线（首屏）

```
← 时间线 ⌄                        ⌕  ⋮
──────────────────────────────────────
2026年11月
┌────┬────┬────┐   gap 4
│    │    │    │   圆角 8，无阴影
├────┼────┼────┤
│    │    │    │
└────┴────┴────┘
2026年10月
...
──────────────────────────────────────
128 项 · 1.4 GB              已选 3 项
```

- 顶栏：64、与页面同色、`titleLarge` 左对齐、右侧 2 个动作（搜索 / 更多）。
- 月份分区标题：`labelMedium` SemiBold、`onSurfaceVariant`、左 4、上 24、下 8。
- 网格：3 列、gap 4、圆角 8、无卡片无阴影；缩略图铺满。
- 多选：长按进入；选中格子加 3px `primary` 内描边 + 右下角圆形勾；顶栏换成"已选 N 项 / 全选"；底栏换成操作条（移动、加入相册、分享、删除、更多）。
- 底部默认只有一条状态条（项数 · 大小），不要同时放导航栏和状态条。

### B. 整理（Cleanup）

```
整理
建议清理 · 3 组
┌──────────────────────────────┐
│ [icon] 重复照片        42 张 ›│
│        预计释放 380 MB        │
├──────────────────────────────┤
│ [icon] 模糊照片        18 张 ›│
├──────────────────────────────┤
│ [icon] 大文件          6 个  ›│
└──────────────────────────────┘
清理后释放约 1.2 GB
[ 查看并清理 ]        [ 稍后 ]
```

- 这是"列表 + 主按钮"的典型：分组卡圆角 16、行 64、1px 分隔；每行一个 chevron。
- 一屏一个主动作：`查看并清理`。`稍后` 是文字按钮，不做第二个实心按钮。
- 删除确认必须用 `error` 实心按钮，文案写"移到回收站，30 天内可恢复"。
- 不要给每个建议项都放一个"删除"按钮——那是把五个主动作塞进一屏。

### C. 设置

```
外观
┌──────────────────────────────┐
│ 主题                跟随系统 ›│
│ 强调色                森林绿 ›│
│ 深色模式                [ ○] │

┌──────────────────────────────┐
```

- 分组卡 16、行左右 16、标题 `bodyMedium` Medium、值 `labelMedium` muted、chevron。
- 组标题 `labelMedium` SemiBold，左 4、下 8、组间距 24。
- 强调色用底部面板选，不用对话框里塞 6 个色块。

### D. 导出 / 幻灯片设置（面板）

- 88% 高、顶角 28、把手、字段组间距 20。
- 字段 ≤7 个：范围、尺寸、格式、质量、目标位置。
- 底部 sticky：`取消`（文字）+ `开始导出`（实心，全宽 60%）。
- 面板里不再弹对话框；需要确认就看 D 的上一级。

## 4. 六条硬改（按顺序做）

1. 换 token：`background` / `primary` / `primaryContainer` / `muted`，一屏之内就能看出变化。
2. 统一字阶：把 12 种字号归到 13 档里的 6 档（22 / 16 / 14 / 12 / 11），删除 `13sp`、`15sp`、`17sp`。
3. 顶栏统一：64、同底色、标题左对齐、右侧 ≤3 个动作。
4. 底栏三选一：状态条 / 选择操作条 / 进度条，不要叠加。
5. 面板统一：88%、28 顶角、主按钮 sticky。
6. 三态统一：空（插画 72 + 一句 + 一个动作）、载（300ms 后骨架）、错（人话 + 原因 + 重试 + 次出口）。

## 5. 灰度检验

改完后做两件事：

- **灰度**：截图转灰度，时间线是否还分得清"分区 / 网格 / 选中 / 主按钮"？分不清说明层级还是靠颜色。
- **并排**：把这张截图和 Zippest 的列表页并排，问没看过两个 App 的人"哪两个是同一系列"。答对即通过。

## 6. 验收

只跑 `references/09-checklist.md` 的 20 项。相册场景下重点看：

- #2 主色克制：网格页的主色只应在选中描边和底栏主操作上。
- #5 字阶：确认 13/15/17 已全部消失。
- #12 底栏互斥：时间线页不能同时出现状态条与导航栏。
- #15 三态：空相册、加载中、读取失败三张都要有。
- #17 选择模型：全选再点一次必须清空但留在选择态。
- #20 动效：网格增删用 200ms，不要弹性回弹。

# 00 · 家族指纹

判断"像不像 Zippest"，不看形容词，看这 12 个可指认的细节。
每一条都给出：为什么、怎么做、什么算走样。

## 1. 两级色阶的纸面

**为什么**：工具类 App 的内容密度高，背景必须退后。纯白打底会让每一块内容都抢注意力，暖灰底 + 纯白表面形成"纸 + 卡"的错觉，又不真的做卡片。

**怎么做**：页面 `background`（浅色 `#F6F7F5`），表面 `surface`（`#FFFFFF`）。两者亮度差很小，靠 1px 描边和色阶区分，不靠阴影。

**走样**：纯白页面 + 灰卡片（反了）；大面积渐变背景；背景里加纹理 / 噪点 / 光斑。

## 2. 深森林绿的单点

**为什么**：一个 App 只需要一个"可以按"的颜色。主色一旦铺开，就变成装饰，主动作反而找不到。

**怎么做**：主色只出现在主按钮、进度、当前导航项、可点链接。同屏主色面积目标 < 5%。

**走样**：主色做标题、做图标底色、做标签、做分割线；一屏出现两种以上强调色。

## 3. 语义色方底图标

**为什么**：列表里每行都有图标，如果每类一个彩色，列表会变成调色盘；全部灰色又失去辨识。折中是"低饱和方底 + 同色系线框图标"。

**怎么做**：容器 40dp、圆角 12、取语义容器的低饱和色；图标 24dp、取对应 content 色。类别到颜色的映射固定（见 06）。

**走样**：图标直接放在行首无底色；用彩虹色区分格式；用 emoji 当图标。

## 4. 扁平行，不是卡片

**为什么**：并列条目之间是"同级"关系，卡片会暗示"每一块都是独立容器"，让列表变重。

**怎么做**：行高 ≥64dp，左右 12dp 内边距，行间 1px `outline` 32% 分隔线；列表外层不加背景色块。

**走样**：每条一个圆角卡 + 阴影；列表外包一层灰底卡；分隔线粗于 1dp 或用主色。

## 5. 顶栏与页面同色

**为什么**：顶栏是"位置指示"，不是"内容块"。抬高它会把页面切成两段。

**怎么做**：64dp，容器色 = `background`，无阴影；标题 `titleLarge`（22sp）左对齐；右侧最多 3 个图标动作。

**走样**：顶栏用主色 / 白色卡片；大标题居中；顶栏放 5 个以上图标。

## 6. 底部一条带

**为什么**：底部是拇指区，但同时只能承担一件事。状态、操作、进度叠在一起会互相挤。

**怎么做**：常驻只有一条——有选中项时是操作条，有长任务时是进度条，否则是状态条。三者互斥，切换用 200ms 淡入。

**走样**：状态条 + 操作条 + 导航栏同时出现；底部再加一个悬浮按钮。

## 7. 88% 底部面板

**为什么**：配置类操作需要上下文，又不能让用户以为离开了页面。全屏太重，半屏（50%）放不下表单。

**怎么做**：`ModalBottomSheet`，`skipPartiallyExpanded = true`，内容高 88%（表单密集可 90%），顶角 28，顶部有拖拽把手。

**走样**：50% 半屏还要内部滚动；面板从中间弹出；面板里再套对话框。

## 8. 单色线性插画

**为什么**：空态需要一点人味，但不能变成营销插画。线性小画 + 一个主色点是"工具的手绘感"上限。

**怎么做**：72dp，1.5dp 线宽，线色 `onSurfaceVariant` 55%，主色只点 1–2 笔（圆点 / 一小段线）。

**走样**：3D 插图、人物、渐变填充、彩色多色插画、大图占半屏。

## 9. 等宽数字

**为什么**：进度、大小、时间在刷新，非等宽字体会让整行左右抖。

**怎么做**：所有字阶带 `fontFeatureSettings = "tnum"`；技术数值可用等宽字体（Roboto Mono）。

**走样**：只有个别地方用等宽；数字用装饰性字体。

## 10. 左对齐的 SemiBold 标题

**为什么**：居中的大标题是营销页语法；工具页需要快速扫读，左对齐更高效。

**怎么做**：页面标题 22–24sp SemiBold 左对齐；首启页可到 24sp，但仍左对齐、与内容同一条左边线。

**走样**：居中 hero 标题 + 副标题 + 插画；标题用全大写英文。

## 11. 短、直、不弹跳的动效

**为什么**：工具的使用频率高，动效越多越烦。

**怎么做**：120ms 点击反馈、200ms 常规过渡、320ms 页面 / 面板入场；只用标准缓动；列表增删用 `animateItem`；尊重系统"减少动态效果"。

**走样**：弹簧回弹、循环呼吸光、shimmer 骨架、视差、页面转场位移超过 24dp。

## 12. 一屏一种强调

**为什么**：同系列靠"克制"识别。多一个强调色、多一个主按钮，立刻像另一套设计。

**怎么做**：进入页面先问"这屏唯一的主动作是什么"；其余动作降级为文字按钮、图标或"更多"。

**走样**：主按钮 + 悬浮按钮 + 底部工具栏三套入口并存；同一屏出现两个实心按钮。

## 六个反指纹（出现即出戏）

1. 任何渐变（按钮、标题、背景、进度条）。
2. 玻璃拟态 / 背景模糊 / 半透明叠层。
3. 霓虹或高饱和强调色（荧光绿、亮蓝、纯红）。
4. emoji 当图标。
5. 列表套卡片、卡片再套卡片。
6. 无限循环动画（呼吸光、旋转装饰、漂浮）。

## 同系列测试（5 问）

把设计稿和一张 Zippest 截图并排，逐条回答：

1. 不看 logo，能否指出"哪个是同一个 App"？
2. 两边的主动作是不是同一个视觉重量？
3. 两边的列表行高与分隔线是不是同一种节奏？
4. 两边有没有出现对方没有的第三种彩色？
5. 把 Zippest 的功能名换成你的，剩下的话术还成立吗？

五问里有两问答不上，就回到 `09-checklist.md` 逐项修。

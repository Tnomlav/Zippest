# 01 · 风格与材质

## 定位

**克制的本地工具。** 三个词，按优先级：可信、好用、安静。

- 可信：信息直给，不修饰；状态永远说清楚。
- 好用：密度高但不挤；每个动作都在拇指够得到的地方。
- 安静：颜色少、动效短、没有装饰性元素。

反面参照（明确不要）：营销落地页、SaaS 仪表盘、社交 feed、拟物皮革、赛博霓虹。

## 材质

只有三种"材质"，没有第四种：

| 层 | 颜色 | 用途 | 边界 |
|---|---|---|---|
| 纸 | `background` | 页面底 | 无 |
| 卡 | `surface` | 列表、面板、对话框、设置分组 | 1px `outlineVariant` 或极轻阴影 |
| 墨 | `onSurface` / `onSurfaceVariant` | 文字与图标 | 无 |

**阴影预算**：一屏最多一层阴影。允许的位置只有：浮动进度条（12dp）、选择工具条（8dp）、对话框（16dp）。列表行、卡片、顶栏一律零阴影。

**描边预算**：分隔线 1px、`outline` 32%；控件描边 1px、`outline`；选中态不用描边，用 `primaryContainer` 45% 填充。

## 密度

- 基准 393×852dp；一屏可见 9–11 行。
- 行高 64dp 起；带两行副文本可到 76dp。
- 区块间距 16–24dp；同组元素 8–12dp。
- 页面左右：列表 12dp，表单 / 面板 20dp；顶部留白 8dp，底部留出系统手势区。

## 留白

留白是这套语言的主要"高级感"来源，规则只有一条：**留白必须成组**。
要么上下都紧（行内），要么上下都松（区块间）；不要出现"上面 4、下面 14"这种无意义差值。

## 语气

界面文案与视觉是同一套语气：陈述、不劝、不感叹。

- 按钮：动词开头，2–6 字（`开始导入`、`保存`、`以后再说`）。
- 标题：名词短语（`任务`、`回收站`、`外观`）。
- 说明：一句话说清后果，不写"轻松""一键""极致"。
- 错误：人话 + 原因 + 出口，不写错误码（错误码折叠进"详情"）。

详见 `07-usage.md` 的文案一节。

## 深色

不是"反色"，是"同一张纸在夜里"。

- 底色 `#121815`，表面 `#1B231F`，层次靠 `surfaceContainer` 五级而不是阴影。
- 主色提亮到 `#7FD6B6`，容器 `#1D4B3A`；不要用白字压深绿。
- 分隔线 `#33403A`；插图线色降到 45% 不透明度。
- 深色下不要出现纯黑 `#000`（除 scrim）。

## 宽屏

- ≥600dp：左侧 240dp 导航栏，内容区不再拉宽。
- ≥840dp：第三栏（信息 / 预览）宽 320dp。
- 宽屏不是"把手机页放大"：行不拉伸、文字行长 ≤ 72 字符、弹层最大宽 640dp 居中。

## 风格对照表

| 像 | 不像 |
|---|---|
| 系统文件管理器、专业音频工具、离线笔记 | 电商首页、社交动态、营销专题 |
| 一行行清晰的信息 | 一张张展示的卡片 |
| 一个绿色按钮 | 到处是品牌色 |
| 1px 线和不明显的层次 | 大圆角 + 弥散阴影 |
| 图标讲功能 | 插画讲故事 |
| 短促的确认动画 | 页面转场表演 |

## 一句话检验

把界面截图的颜色抽掉、变成灰度，它仍然应该"看得出层级、找得到主动作"。
如果灰度下就散了，说明层级是靠颜色撑的，回到 `04-composition.md` 重排。

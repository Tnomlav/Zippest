# 02 · 配色

配色不是一组好看的色值，是**一组角色 + 一套使用规则**。角色固定，色值可换；规则不可换。

## 角色表（浅色 / 深色）

| 角色 | 用途 | Light | Dark |
|---|---|---|---|
| `background` | 页面底色 | `#F6F7F5` | `#121815` |
| `surface` | 列表、面板、对话框、分组卡 | `#FFFFFF` | `#1B231F` |
| `onSurface` / `onBackground` | 主文字、图标 | `#1B211E` | `#E8EEE9` |
| `surfaceVariant` | 次级块、输入框底、进度轨道 | `#E9EFEA` | `#2A342E` |
| `onSurfaceVariant` | 次要文字、说明、未选中图标 | `#59625D` | `#B8C4BB` |
| `outline` | 控件描边 | `#7D8C82` | `#66766B` |
| `outlineVariant` | 分隔线、极轻描边 | `#DDE4DE` | `#33403A` |
| `primary` | 主按钮、进度、当前项、可点链接 | `#0F6B4F` | `#7FD6B6` |
| `primaryContainer` | 选中底、轻强调 | `#D9F2E7` | `#1D4B3A` |
| `onPrimaryContainer` | 容器上的文字 / 图标 | `#083B2B` | `#C8F4E2` |
| `secondary` | 媒体类对象的图标色 | `#4F6B5E` | `#A9C7B8` |
| `secondaryContainer` | 媒体类图标底、提示条 | `#DCE9E2` | `#2A3B34` |
| `tertiary` | 工具类对象（归档、导出物、安装包） | `#41586A` | `#A8C0D4` |
| `tertiaryContainer` | 工具类图标底 | `#D6E3EE` | `#2A3B48` |
| `error` | 失败、破坏性、风险 | `#A24617` | `#F0A07A` |
| `errorContainer` | 错误提示底、危险图标底 | `#FBE7DC` | `#6B2A0F` |

`surfaceContainerLowest / Low / Container / High / Highest` 五级只用于深色层次和骨架屏，浅色下基本等于白与纸之间的一点点差值。

## 使用规则（硬性）

1. **主色 = 行动色。** 只允许出现在：主按钮、进度条、当前导航项、可点链接、复选框。
2. **警示色 = 风险色。** 只允许出现在：失败态、破坏性确认按钮、权限 / 隐私等风险说明。不要用它做"重要"。
3. **同屏一种强调。** 主色与警示色不同屏争抢；确需同屏时，警示色面积必须小于主色。
4. **彩色只给"对象类型"，不给"重要性"。** 类型色见 `06-icon-motion.md`。
5. **选中态不用描边。** 用 `primaryContainer` 45% 填充整行。
6. **分隔线 = `outline` 32%**，永远 1px；不要用 `outlineVariant` 画在深色底上（对比不够）。
7. **文字对比度 ≥ 4.5:1，控件描边 ≥ 3:1。** 已测：`#59625D` on `#FFFFFF` = 6.31:1；`#0F6B4F` on `#FFFFFF` = 6.49:1；`#A24617` on `#FFFFFF` = 6.1:1；`#7D8C82` on `#FFFFFF` = 3.53:1。
8. **深色不反色。** 主色提亮、容器加深，文字用 `#E8EEE9`；不要用纯白文字压深绿按钮。
9. **错误提示底用 `errorContainer`，不要用 10% 红。** 低透明度红在深色下几乎不可见。

## 强调色（可选）

强调色只替换 `primary / primaryContainer / onPrimaryContainer / inversePrimary` 四个位置，其余角色不动。
这是"同一系列的不同配色"，不是"另一套设计"。

| 名称 | Light primary | Light container | Dark primary | Dark container |
|---|---|---|---|---|
| 森林绿（默认） | `#0F6B4F` | `#D9F2E7` | `#7FD6B6` | `#1D4B3A` |
| 海蓝 | `#1E5FA8` | `#DCE9F8` | `#8FC2FF` | `#1B3A5C` |
| 紫罗兰 | `#6A4C93` | `#EDE4F7` | `#C9AEF0` | `#3A2B52` |
| 琥珀 | `#A8561C` | `#F7E5D6` | `#F0B183` | `#4A2C16` |
| 玫瑰 | `#A8365A` | `#F8DFE6` | `#F2A6BC` | `#4C2030` |
| 石墨 | `#3F4A45` | `#E2E7E4` | `#C2CFC8` | `#2B342F` |

要求：新强调色的容器必须能在浅色下承载 `onPrimaryContainer`（深一档的同色），并且主色对白 ≥4.5:1。
换色不换语义：换了海蓝，蓝色也只是"行动色"，不能顺手拿来做装饰。

## 禁用

- 渐变（任何方向、任何两色）。
- 主色铺大面积（标题条、背景、整卡）。
- 一个屏出现两种以上非语义彩色。
- 半透明彩色叠层（玻璃感）。
- 纯黑背景、纯白文字。
- `#FF0000` 这类系统红做错误色；错误色必须偏暖（`#A24617` / `#F0A07A`）。

## 快速判断

- 把截图缩到 10% 大小，还看得到的那点颜色，就是你这屏的强调色。它应该只有一个位置。
- 如果去掉所有颜色，层级仍然成立，说明配色用对了；如果一去掉就散，说明在拿颜色当结构。

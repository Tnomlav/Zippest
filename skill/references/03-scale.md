# 03 · 字阶、间距、圆角、尺寸、动效

所有数值都是 token 的取值，不允许在界面里写表外数字。4dp 是唯一基线。

## 字阶（13 档，全部等宽数字）

| 样式 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| `displaySmall` | 32 / 40 | SemiBold | 空态大标题（慎用） |
| `headlineLarge` | 28 / 36 | SemiBold | 首启页主标题 |
| `headlineMedium` | 26 / 34 | SemiBold | 页面级大标题 |
| `headlineSmall` | 24 / 32 | SemiBold | 页面标题、对话框标题 |
| `titleLarge` | 22 / 28 | SemiBold | 顶栏标题、分区大标题 |
| `titleMedium` | 16 / 24 | SemiBold | 卡片标题、设置项标题 |
| `titleSmall` | 14 / 20 | Medium | 卡内小标题 |
| `bodyLarge` | 16 / 24 | Regular | 正文强调 |
| `bodyMedium` | 14 / 20 | Regular | 默认正文、列表主文 |
| `bodySmall` | 12 / 16 | Regular | 辅助说明 |
| `labelLarge` | 14 / 20 | Medium | 按钮文字 |
| `labelMedium` | 12 / 16 | Medium | 标签、角标、次要信息 |
| `labelSmall` | 11 / 16 | Medium | 极小脚注 |

规则：

- 字号一律 `sp`，行高随字号给定，不要用 `dp` 写字号。
- 全部带 `fontFeatureSettings = "tnum"`：进度、大小、时间刷新时不左右跳。
- 中文行高 ≈ 1.5 × 字号，标题 ≈ 1.3 ×。
- 正文行长 ≤ 72 字符；超过就加宽边距或分栏。
- 200% 系统字号下：标题允许换行、主按钮允许两行、列表长名省略号，不允许截断。

## 间距（4dp 基线）

| Token | 值 | 用途 |
|---|---|---|
| `xs` | 4 | 行内元素 |
| `sm` | 8 | 图标与文字、行内块 |
| `md` | 12 | 控件内边距、列表左右 |
| `lg` | 16 | 区块间距（默认） |
| `xl` | 20 | 页面版心、面板左右 |
| `xxl` | 24 | 大区块、对话框内边距 |
| `xxxl` | 32 | 分段、首启页 |
| `huge` | 40 | 空态留白 |

规则：

- 列表左右 12（`md`），表单 / 面板 / 对话框左右 20（`xl`）。
- 列表上下 content padding 8；行内上下 8。
- 不允许出现 2 / 6 / 10 / 14 / 18 这类值；就近归到 4 的倍数。
- 一个大区块的对齐线只有一条：所有元素左边或右边对齐同一列，不混用。

## 圆角

| Token | 值 | 用途 |
|---|---|---|
| `xs` | 8 | 小控件、输入框、缩略图 |
| `sm` | 12 | 图标容器、按钮、列表内小块 |
| `md` | 16 | 设置分组、卡片、任务卡 |
| `lg` | 20 | 面板、内嵌预览 |
| `xl` | 24 | 大面板、首启图标容器 |
| `sheet` | 28 | 底部弹层顶角、对话框 |
| `pill` | 999 | 胶囊标签、进度条 |

规则：手机屏幕内圆角不超过 24；弹层与对话框用 28；**不要所有东西都是全圆角**——胶囊只给 chip 和进度条。

## 尺寸

| Token | 值 | 说明 |
|---|---|---|
| `iconSm` | 20 | 行内小图标 |
| `icon` | 24 | 标准线框图标 |
| `touchTarget` | 48 | 可点区域下限（含图标按钮的隐形热区） |
| `rowMin` | 64 | 列表行高下限（64–76） |
| 类型图标容器 | 40 | 圆角 12，内含 24 图标 |
| 缩略图 | 44 | 圆角 12（列表行内） |
| 顶栏 | 64 | 与页面同色 |
| 底部操作带 | ≥64 | 另加系统手势区 padding |
| 空态插画 | 72 | 线宽 1.5 |
| 首启图标容器 | 76 | 圆角 24，内含 36 图标 |

## 动效

| Token | 值 | 用途 |
|---|---|---|
| `fast` | 120ms | 点击反馈、颜色过渡 |
| `normal` | 200ms | 展开、增删、状态切换 |
| `slow` | 320ms | 页面 / 面板入场 |

规则：

- 只用标准缓动（ease-out 进，ease-in 出）；不要弹簧、不要回弹。
- 位移 ≤ 24dp；透明度变化优先于位移。
- 列表增删用 `animateItem()`；系统"减少动态效果"开启时直接切换。
- **禁止无限循环动画**：呼吸光、shimmer、漂浮、旋转装饰。骨架屏用静态灰条。
- 进度条用真实进度，不做"假装在动"的循环。

## 数字与单位

- 进度：`46%`，百分比与数字之间不加空格。
- 大小：`24.8 MB`，单位前一个空格；TB / GB / MB / KB 顺序换算。
- 时间：相对时间优先（`22 小时前`、`昨天`），绝对时间 `2026年9月29日`。
- 速度：`11.4 MB/s`；剩余时间：`约 5 秒` / `约 2 分钟`。
- 计数：`已选 3 项`、`12 项`，数字与量词之间空格。

## 一页的字号预算

同屏最多 4 种字号。典型组合：

- 列表页：`titleLarge` 标题 + `bodyMedium` 行主文 + `labelMedium` 行副文 + `labelMedium` 底栏。
- 面板：`headlineSmall` 面板标题 + `titleSmall` 字段名 + `bodyMedium` 输入 + `labelMedium` 说明。
- 空态：`headlineSmall` 标题 + `bodyMedium` 说明 + `labelLarge` 按钮。

超过 4 种，说明在用字号代替层级，回到 `04-composition.md` 用留白和分组解决。

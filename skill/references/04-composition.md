# 04 · 构图

## 画布

| 断点 | 宽度 | 布局 |
|---|---|---|
| COMPACT | < 600dp | 单栏（基准 393 × 852） |
| MEDIUM | 600–839dp | 左导航 240 + 内容 |
| EXPANDED | ≥ 840dp | 左导航 240 + 内容 + 第三栏 320 |

安全区：顶部状态栏、底部手势条都要避让；底部操作带额外加 `navigationBarsPadding`。
内容永远不贴屏幕边：列表左右 12，表单左右 20。

## 页面骨架

```
┌──────────────────────────────┐
│ 顶栏 64：← 标题 ⌄      ⌕ ＋ ⋮ │  ← 与页面同色，无阴影
├──────────────────────────────┤
│                              │
│ 内容区（列表 / 网格 / 表单）    │  ← 只有这一层滚动
│                              │
├──────────────────────────────┤
│ 底部一条带（状态 / 操作 / 进度）│  ← 常驻，与内容互斥
└──────────────────────────────┘
```

三条硬规则：

1. **顶栏只有一个**，不做双层标题栏、不做可折叠大标题。
2. **内容区是唯一滚动容器**；顶栏与底栏固定，不随滚动隐藏。
3. **底栏同时只有一件事**：状态条、操作条、进度条三选一。

## 五套标准构图

### A. 列表页（最常用）

```
← 当前位置 ⌄                    ⌕ ＋ ⋮
──────────────────────────────────────
[icon] 主文                      副文  ›
──────────────────────────────────────
[icon] 主文                      副文  ›
──────────────────────────────────────
...
──────────────────────────────────────
已用 436 GB / 491 GB        可用 55 GB
[━━━━━━━━━━━━━━━━━━━━━━━━━━━━]
```

- 顶栏：返回 + 可下拉的当前位置 + 3 个动作（搜索 / 新建 / 更多）。
- 列表：扁平行、1px 分隔、无外层卡片。
- 底栏：状态条（一条细进度 + 两个数字），选中后让位给操作条。
- 可选：列表顶部一条横向"最近"卡片带（高 64–72，宽 190，圆角 12，浅底）。

### B. 详情 / 预览页

```
← 对象名                        ⋮
──────────────────────────────────────
        内容（图 / 文 / 预览）
──────────────────────────────────────
元信息：类型 · 大小 · 时间 · 位置
──────────────────────────────────────
[次要动作]              [主操作]
```

- 内容居中，最大宽 640（宽屏）；元信息左对齐成组。
- 底部动作区最多 1 主 + 1 次；超过 2 个进"更多"。

### C. 任务 / 长任务页

```
任务
进行中  1 项
┌──────────────────────────────┐
│ 标题                          │
│ 状态文案            取消  暂停 │
│ 速度 · 剩余          46%      │
│ [━━━━━━━━━━━━━━━━━━━━]        │
└──────────────────────────────┘
已结束  2 项
┌ 标题 / 结果文案 ─────────────┐
└──────────────────────────────┘
```

- 分组标题：`labelMedium` SemiBold + 计数。
- 卡片：`surface`、圆角 16、无阴影（除非它是浮动的）。
- 进行中卡片必须有：标题、状态、一个百分比、一条进度、两三个动作（取消 / 暂停）。
- 已结束卡片只有标题 + 结果一句话 + 时间。

### D. 设置页

```
设置
分组标题
┌──────────────────────────────┐
│ 项标题            当前值  ›   │
│ ──────────────────────────── │
│ 项标题            当前值  ›   │
└──────────────────────────────┘
分组标题
┌──────────────────────────────┐
│ 开关项                 [ ○]  │
└──────────────────────────────┘
```

- 分组 = `labelMedium` 标题 + 圆角 16 的白卡；卡内行 16dp 内边距。
- 每行右侧只有一个信息：当前值 + chevron，或一个开关；不要既放值又放按钮。
- 分组不超过 8 行；超过就再分一组。

### E. 首启 / 空态引导页

```
[76dp 图标容器]
标题 24sp
一段说明（≤2 行）
✓ 要点一
✓ 要点二
✓ 要点三
[ 主按钮 52dp 全宽 ]
[ 文字按钮 ]
脚注 11sp
```

- 左对齐，与内容同一条左边线；不居中。
- 最多 3 条要点；每条一行。
- 主按钮全宽、52dp 高；次动作是文字按钮。

## 底部面板（sheet）

```
        ── 把手 ──
标题 24sp
副标题 / 计数 12sp
字段组
字段组
[取消]            [主操作]
```

- 高 88%（表单密集 90%），顶角 28，`skipPartiallyExpanded`。
- 打开后焦点在第一个可编辑项；键盘弹出时内容上移，按钮始终可见。
- 面板内不再套面板；需要二次确认时用对话框。

## 对话框

- 宽 300–340，圆角 28，左右 20 外边距，内边距 24 / 28。
- 结构：可选 58dp 圆形图标 → 标题 22sp → 说明 14sp → 两个按钮（左次右主，各占一半）。
- 破坏性对话：图标底 `errorContainer`，确认按钮实心 `error`，默认焦点在取消。
- 输入类对话：标题 + 一行说明 + 输入框 + 按钮；不放大段文字。

## 三态的锚点

空 / 载 / 错三态都锚在内容区**顶部 30%**，内容整体居中，不随内容高度漂移。

```
内容区
  30% ──── 空态 / 骨架 / 错误 从这里开始
```

- 空态：插画 72 → 标题 → 一句说明 →（可选）一个动作。
- 载入：300ms 后才出骨架（6 行 56dp 灰条，圆角 12），避免一闪。
- 错误：插画 → 标题 → 原因（>60 字折叠"详情"）→ 重试 + 次出口。

## 宽屏构图

```
┌────────┬──────────────────────┬──────────┐
│ 导航    │ 列表 / 网格           │ 预览 / 信息│
│ 240    │ 自适应                │ 320      │
└────────┴──────────────────────┴──────────┘
```

- 导航栏：当前位置层级（可点回跳）+ 当前层的子分组；选中项用 `primaryContainer` 底、圆角 12。
- 第三栏：选中项的预览；没有选中项时显示当前位置的摘要。
- 宽屏下弹层最大宽 640 并居中；列表行不拉伸，仍在内容列内。

# 05 · 组件

每个组件只写"长什么样、多大、什么颜色、什么状态"，不写业务。

## 列表行

```
[✓] [40dp 图标] 主文 14sp Medium          副文 12sp  ›
                副文 12sp muted
```

| 项 | 规格 |
|---|---|
| 高 | ≥64dp（两行副文 76dp） |
| 内边距 | 左右 12，上下 8 |
| 主文 | `bodyMedium` + Medium，单行省略 |
| 副文 | `labelMedium`，`onSurfaceVariant`，用 ` · ` 连接 |
| 前导 | 40dp 语义色方底图标（圆角 12）或 44dp 缩略图 |
| 尾部 | 只放一个：chevron / 图标按钮 / 无 |
| 选中 | 整行 `primaryContainer` 45% 填充；不加边框 |
| 分隔 | 1px `outline` 32%，通栏（不缩进） |
| 点击 | 整行可点，热区 ≥64dp |

不要：行内放两个以上尾部动作；行内嵌套按钮组；给行加圆角或阴影。

## 语义图标容器

| 项 | 规格 |
|---|---|
| 容器 | 40dp，圆角 12 |
| 图标 | 24dp 线框，1.5–2dp 描边 |
| 底色 | 语义容器色（见 06 的映射） |
| 前景 | 对应 content 色 |

## 顶栏（三种状态，互斥）

### 常规

`←` + 标题（可带下拉箭头）+ 右侧 ≤3 个图标按钮。
容器色 = `background`，高 64，无阴影。标题 `titleLarge`。

### 选择态

`×` + `已选 N 项` / `点按选择` 两行 + 右侧全选复选框。
关闭按钮语义必须是"退出选择"；全选框与行内复选框同款。

### 搜索态

`←` + 无边框输入框 + 右侧范围切换（当前 / 全部）+ 清空。
输入框透明底、无下划线；占位文案说明范围。

## 底部条（三选一）

### 状态条

```
本机存储 · 已用 436 GB / 491 GB      可用 55 GB
[━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━]
```

- 高 56–64 + 手势区；`surface` 底 + 顶部 1px 线。
- 左：一句状态；右：一个数字；下：4dp 胶囊进度。

### 操作条（选择态）

- 高 ≥64 + 手势区；`surface` + 8dp 阴影。
- 4–5 个"图标 24 + 文字 12"等宽项 + 一个"更多"。
- 图标与文字都用 `onSurface`，不用主色；主操作靠位置（第一项），不靠颜色。
- 危险动作永远排最后，或收进"更多"。

### 进度条

- 浮动卡片：左右 12、下 7；圆角 16；`surface`；阴影 12。
- 行：34dp 圆形图标容器 + 标题 / 状态 + 右侧百分比。
- 下：5dp 胶囊进度，轨道 `surfaceVariant`，进度 `primary`。
- 点击整卡进入任务页。

## 按钮

| 类型 | 规格 | 用途 |
|---|---|---|
| 主按钮 | 高 48–52，圆角 12，`primary` 实心，白字 `labelLarge` | 每屏一个 |
| 文字按钮 | 高 48，无底，`primary` 字（次要用 `onSurfaceVariant`） | 次要 / 取消 |
| 破坏性按钮 | 高 48，圆角 12，`error` 实心，`onError` 字 | 仅确认对话框 |
| 图标按钮 | 48 热区，24 图标 | 顶栏 / 行尾 |

规则：

- 主按钮不并排两个；确需并排时，另一个必须是文字按钮。
- 按钮文字不用省略号换行；200% 字号允许两行。
- 禁用态只降透明度到 38%，不改色相。

## 选项片（chip）与分段

- chip：高 36，圆角 999，1px `outline`，选中 `secondaryContainer` 底 + `onSecondaryContainer` 字。
- 横向排布，间距 8；超出一行横向滚动，不换行成两排。
- 分段选择（2–4 项）：等宽、圆角 12、选中实心浅底；不要用 Tabs 做参数选择。

## 输入框

- 高 56，圆角 12，1px `outline` 描边，底色 `surface`。
- 聚焦：描边 `primary` 2px；错误：描边 `error` + 下方 12sp 说明。
- 标签在框内上方或浮动；占位文案给例子，不给指令。
- 密码框右侧必须有"显示 / 隐藏"图标。

## 设置分组

- 外卡：`surface`，圆角 16，`tonalElevation 1dp`，无阴影。
- 行：左右 16、上下 16；标题 `bodyMedium` Medium；右侧值 `labelMedium` muted + chevron。
- 组标题：`labelMedium` SemiBold，`onSurfaceVariant`，左 4、下 8。
- 组间距 24。

## 菜单

- 圆角 16，`surface`，阴影 4–8；每项高 48，左图标 20 + 文字 14，间距 12。
- 危险项文字 `error`，放在最后，与上一项之间加 1px 分隔。
- 菜单从触发点展开（锚定），不做全屏弹层。

## 提示条（snackbar）

- 反色底 `inverseSurface` / `inverseOnSurface`，圆角 12。
- 距底部手势区 8；左对齐；最多 2 行；可带 1 个动作。
- 出现 4 秒后自动消失；带动作时 7 秒。
- 不用 toast，不用顶部横条。

## 进度

- 线性：高 4–5，圆角 999，轨道 `surfaceVariant`，进度 `primary`。
- 不确定态用不确定动画（系统默认），不要自绘循环光。
- 环形：只在"整页加载"用，24–32dp，`primary`。

## 任务卡

- `surface`、圆角 16、内边距 16/12、无阴影。
- 结构：标题 → 状态文案 → 进度 + 百分比 → 两个动作（取消 / 暂停或继续）。
- 动作图标 20，文字 12，间距 8；暂停用 `primary`，取消用 `onSurfaceVariant`。

## 对话框

- 宽 300–340；圆角 28；内边距 24/28；标题 22 SemiBold；说明 14 muted。
- 图标容器 58 圆形（危险用 `errorContainer`）。
- 按钮一行两个，各 50%，间距 12，高 48。
- 输入类：输入框全宽，按钮在下方。

## 底部面板

- 顶角 28，高 88%，把手 32×4 圆角 999，颜色 `outlineVariant`。
- 标题 24 + 副标题 12 muted；字段组间距 20；底部按钮行 sticky。
- 关闭：下滑手势 + 返回键；不要右上角再加一个 ×。

## 徽标与角标

- 计数角标：高 16–18，圆角 999，`error` 底白字 11sp；最多显示 `99+`。
- 状态角标：`labelSmall` + `primaryContainer` 底，圆角 8；只用于"进行中""已暂停"这类状态。

## 组件组合的三条禁令

1. 不要把行做成卡片，也不要把卡片塞进行。
2. 不要在同一个视觉层里放两个主按钮。
3. 不要在弹层里再开弹层；需要第二层就回退成对话框或整页。

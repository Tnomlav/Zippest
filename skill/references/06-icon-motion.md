# 06 · 图标、插画、动效

## 图标

- **网格** 24dp；**线框**（outlined）；描边视觉重量约 1.5–2dp；端点圆角。
- 小号 20dp（行内、导航、菜单），标准 24dp（行首容器内、顶栏）。
- 只用一种图标族（Material Symbols Outlined 或同风格），不混用实心与线框。
- 图标不单独承担语义：要么有文字，要么有 `contentDescription`。

## 类型 → 颜色映射

颜色只表达"这是什么类对象"，不表达重要性。容器取语义容器色，图标取对应 content 色。

| 类型 | 容器 | 图标色 |
|---|---|---|
| 分组 / 文件夹 | `primaryContainer` | `primary` |
| 工具类对象（归档、导出物、安装包） | `tertiaryContainer` | `tertiary` |
| 媒体（图 / 视频 / 音频） | `secondaryContainer` | `secondary` |
| 文档 / 代码 / 其他 | `surfaceVariant` | `onSurfaceVariant` |
| 未知 / 兜底 | `surfaceContainerHigh` | `onSurfaceVariant` |

规则：

- 最多 5 组颜色，不按扩展名给每类一个色。
- 图标容器 40dp、圆角 12；缩略图 44dp、圆角 12。
- 有真实缩略图时优先用缩略图，没有才退回类型图标；视频缩略图右下角加 20dp 播放角标（圆形、`scrim` 40% 底、白图标）。

## 插画（空态 / 错误 / 引导）

- 尺寸 72dp（首启图标容器 76dp、圆角 24）。
- 单色线稿：线色 `onSurfaceVariant` 55%，线宽 1.5dp。
- 主色只点 1–2 笔：一个小圆点，或一小段线。
- 构图极简：一个主体 + 一个动作暗示，不画场景、不画人、不画阴影。
- 四种基本母题够用：分组、清空、任务、搜索。

禁止：3D、渐变填充、多色插画、人物、照片、贴纸风、emoji 拼贴。

## 动效

| 场景 | 时长 | 说明 |
|---|---|---|
| 点击反馈（涟漪、按下态） | 120ms | 不位移 |
| 颜色 / 图标切换 | 120ms | 交叉淡入 |
| 列表增删 | 200ms | `animateItem`，高度 + 透明度 |
| 展开 / 收起 | 200ms | 高度或透明度，不用弹簧 |
| 页面 / 面板入场 | 320ms | 位移 ≤ 24dp + 淡入 |
| 面板退场 | 200ms | 先淡出再位移 |

规则：

- 只用标准缓动；不做回弹、不做 overshoot。
- 同类元素用同一个时长，不要一处 150 一处 250。
- 进度类界面用真实数据驱动，不做装饰性动画。
- "减少动态效果"开启时：列表增删直接切换，页面转场变淡入，所有装饰动画为 0。
- 禁止：无限循环（呼吸光、shimmer、漂浮）、视差、背景粒子、加载完成后的庆祝动画。

## 状态图标

| 状态 | 表现 |
|---|---|
| 进行中 | `primary` 进度 + 百分比 |
| 已暂停 | 图标 `pause`，文字说明"已暂停"，进度保留 |
| 失败 | `error` 图标（`errorContainer` 底）+ 一句话原因 |
| 完成 | 对勾 20dp `primary`，不弹庆祝层 |
| 等待 | 中性文字"等待开始"，不用转圈 |

## 无障碍

- 纯图标按钮必须有 `contentDescription`（动词 + 对象，如"暂停任务"）。
- 列表行合并语义：读出一行 = 主文 + 类型 / 大小 + 时间 +（选中态）。
- 图标不做唯一信息来源：颜色 + 图标 + 文字三者至少两个。
- 触达 ≥48dp；图标本身可以 24，但热区必须补到 48。

# 07 · 使用逻辑

这一份回答"为什么这样安排"，不回答"怎么点"（那是 08）。

## 信息架构

- **打开即内容。** 不做欢迎页、不做启动插画、不做"开始使用"。
- **层级 ≤ 3。** 根 → 分组 → 对象。再深就是设计问题，不是导航问题。
- **一个 App 一个主场景。** 主场景占首屏；次要场景进"更多"或设置。
- **位置稳定。** 同一功能永远在同一个位置；不要按状态把它挪到别处。

## 入口与动作分级

每屏先列出所有可做的动作，然后强制分级：

| 级别 | 数量 | 表现 |
|---|---|---|
| 主操作 | 1 | 实心主按钮，或底部操作条第一项 |
| 次操作 | 1–2 | 文字按钮 / 图标按钮 |
| 其余 | n | "更多"菜单 |

判定主操作的三个问题：

1. 用户打开这一屏，八成是想做这件事吗？
2. 这件事失败会有后果吗？（有后果的更适合做主操作，因为需要确认）
3. 它需要参数吗？（需要参数的走面板，面板里的确认键就是主操作）

## 一屏一主动作

- 进入选择 / 编辑态：原来的主入口让位，主操作变成"对选中的这批做什么"。
- 有长任务进行时：底部让位给进度条，不要再叠一个"新建"按钮。
- 弹层打开时：弹层里的确认键是唯一主操作，背后的页面按钮全部不可见或禁用。

## 破坏性操作

- 菜单里**永远排最后**，与安全项之间有 1px 分隔。
- 需要二次确认；确认按钮是实心 `error`，默认焦点在"取消"。
- 同类选项里，破坏性的一档也排最后：`重命名 → 跳过 → 覆盖`，不是反过来。
- 能撤销的就不要确认（例如进回收站）；不能撤销的必须确认。
- 文案必须说清后果："移到回收站，可在 30 天内恢复" / "永久删除，无法恢复"。

## 批量操作

- 批量入口只有一个：多选。不要另做"批量模式"开关。
- 批量默认**复用同一个输入**：一次密码、一次目标位置、一次命名规则；个别不同的再单独问。
- 批量执行前给一行摘要：`已选 12 项 · 目标：相册`。
- 批量失败不要整批回滚后静默；列出失败项 + 原因 + 重试入口。

## 长任务

三件套，缺一不可：

1. **后台队列**：离开页面继续跑，锁屏继续跑；系统杀掉后可恢复。
2. **浮动进度条**：任何页面底部都能看到当前任务 + 百分比，点击进任务页。
3. **任务页**：进行中 / 已结束两组；可暂停、继续、取消；结束后给结果位置。

规则：

- 长任务的启动必须来自一次明确确认（面板里的主按钮），不能点一下就默默开始。
- 进度要给"可判断"的信息：`99/301 项`、`11.4 MB/s`、`约 5 秒`，不要只给一个转圈。
- 暂停不是取消：暂停保留进度，取消要确认。
- 完成提示要能一键到达结果位置，而不是只说"完成"。

## 搜索

- 搜索作用于"当前范围"，范围可切换：`当前分组 / 全部`。
- 范围写在占位文案和切换按钮上，不让用户猜。
- 跨范围结果必须显示所在位置，否则结果不可用。
- 搜索态替换顶栏标题，不新开页面。
- 无结果 = 空态模板 + 一句"换个关键词或切换范围"，不要只写"无结果"。

## 设置

- 按"用户会一起改的东西"分组，不按代码模块分组。
- 每组 ≤8 行；组内顺序：常用 → 少用 → 危险。
- 设置项就地生效，不需要"保存"；需要重启的必须写明。
- 每项右侧只放一个信息：当前值，或开关。
- 关于 / 隐私 / 许可放在最后一组，不占主路径。

## 三态

| 状态 | 必须给 | 不允许 |
|---|---|---|
| 空 | 插画 + 一句解释 + 一个可行动作（可选） | 只写"暂无数据" |
| 载入 | 300ms 后出骨架；>3s 给一句"仍在加载" | 白屏、转圈超过 3s 无解释 |
| 错误 | 人话 + 原因（长文折叠）+ 重试 + 次出口 | 只给错误码、只给"重试" |

空态的动作必须真的能解决问题：`去其他位置看看`、`新建`、`导入`。
错误态的次出口必须真的有用：`换个位置`、`检查权限`、`稍后再试`。

## 文案

- 陈述句，不劝、不感叹、不用"！"。
- 按钮动词开头，2–6 字；标题名词短语。
- 不用"轻松""一键""极致""智能"这类形容词。
- 数字 + 单位：`24.8 MB`、`约 5 秒`、`已选 3 项`。
- 术语保留原写法：`API`、`Wi-Fi`、`GB`；不要为了句首大写把 `Wi-Fi` 写成 `Wi-fi`。
- 错误文案三段式：发生了什么 → 为什么 → 可以怎么办。
- 不用 emoji；不用全大写英文做标签。

## 渐进披露

- 首屏只放"现在要决定的"；高级参数收进"更多选项"，但**不能藏掉会影响结果的参数**（例如会覆盖同名对象）。
- 面板里字段 ≤7 个；超过就分两步或分组。
- 默认值必须能覆盖 80% 的场景；默认值要写出来，不要留空让用户猜。

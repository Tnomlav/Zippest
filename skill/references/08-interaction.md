# 08 · 交互逻辑

这一份回答"怎么点、点了之后发生什么"。

## 基本手势

| 手势 | 行为 |
|---|---|
| 单击 | 执行该元素的主行为（打开 / 选中 / 触发） |
| 长按 | 进入多选并选中当前项；给一次触觉反馈 |
| 横向滑动 | 不用。列表不做滑动操作（swipe action） |
| 纵向滚动 | 只有内容区滚动 |
| 边缘滑动 | 交给系统返回手势，**不自绘边缘热区** |
| 下滑 | 关闭底部面板 |

原则：手势是加速器，不是唯一入口。任何手势能做的事，必须有可点的等价入口。

## 选择模型（逐条照做）

1. 长按任意行 → 进入选择态，并选中该行。
2. 选择态下，单击行 = 切换选中，不再打开。
3. 选择态下，顶栏变成：`×` + `已选 N 项` + 全选复选框；底栏变成操作条。
4. 顶栏全选复选框语义：
   - 未全选 → 点一下全选；
   - 已全选 → 点一下**清空选择，但仍留在选择态**（不要顺手退出）。
5. `×` 退出选择态并清空；系统返回键同样先退出选择态。
6. 选择数为 0 时，操作条保持可见但动作禁用；提示文案为"点按项目继续选择"。
7. 选中行视觉：整行 `primaryContainer` 45%，勾选框出现（48dp 热区），行尾动作隐藏。
8. 进入选择态后，原来的主入口（新建 / 搜索）从顶栏撤下。
9. 离开页面再回来，选择态可以保留，但必须能从顶栏看清"还在选择"。

## 返回

优先级从高到低：

1. 有弹层 → 关弹层。
2. 在搜索态 → 退出搜索，恢复原顶栏。
3. 在选择态 → 退出选择。
4. 有未提交的编辑 → 询问是否放弃（只有真的会丢数据时才问）。
5. 不在根 → 回上一级。
6. 在根 → 退出 App。

规则：

- 返回是"退一层"，不是"回首页"。不要用返回直接跳回根。
- 返回按钮与系统返回手势行为必须一致。
- 不要在根目录拦截返回做"再按一次退出"这类彩蛋。

## 弹层

- 打开：从底部升起，320ms；焦点进入面板。
- 关闭：下滑、点遮罩、返回键三者等价；有未保存内容时先确认。
- 打开时背景不可操作（遮罩拦截），不做"边看边改"。
- 面板内滚动到顶部时继续下滑才关闭，避免误触。
- 键盘弹出时整体上移，确认按钮始终可见；键盘收起后恢复。

## 对话框

- 只用于"确认后果"和"填一个短输入"，不用于展示长内容。
- 危险确认：默认焦点在取消；点遮罩不关闭（防止误关后以为已取消）。
- 输入对话：回车提交（`ImeAction.Done`）；空输入时确认禁用。
- 一次只开一个对话框；需要第二个就先关掉第一个。

## 搜索交互

- 点搜索 → 顶栏原地变成输入框并自动聚焦，键盘弹起。
- 输入即时过滤（≤300ms 防抖），不按回车才出结果。
- 范围切换即时生效，不重置关键词。
- 清空按钮：有内容才出现；点一次清空并保持焦点。
- 退出搜索：返回键或左上返回，恢复到进入前的滚动位置。

## 反馈的四层

| 层 | 时机 | 形式 |
|---|---|---|
| 即时 | 按下 / 勾选 | 涟漪、勾选框、120ms 颜色变化 |
| 局部 | 单行数据变化 | 行内文字 / 图标更新，200ms |
| 全局 | 一次操作的结果 | 底部提示条，1 个动作，≤2 行 |
| 后台 | 长任务 | 浮动进度条 + 系统通知 |

规则：

- 有明确结果的操作必须给全局反馈；不要"点了没反应"。
- 提示条只说结果 + 一个去处（"已移到回收站 · 撤销"）。
- 连续操作不要连发提示条；合并成一条。
- 长任务的通知与页内进度必须同源，不能一个 46% 一个 52%。

## 并发与禁用

- 长任务进行中：允许浏览，禁用会改变输入的操作（删除源、移动）。
- 传输 / 批量操作进行中：点击行只允许进入分组，不允许打开对象。
- 禁用不是隐藏：禁用项保留位置，降低透明度并说明原因（长按或副文）。
- 同一对象不要同时挂两个会互相影响的任务；后一个排队并显示"等待前一个"。

## 状态保持

- 返回上一级再进来：滚动位置、排序、筛选保持不变。
- 切换主场景：各自的滚动位置独立保存。
- 旋转 / 分屏 / 折叠展开：当前对象与选择态保留，布局按断点重排。
- 进程被杀后恢复：至少恢复到"哪个位置"，进行中的任务从队列恢复。

## 宽屏交互

- 左导航点击 = 回跳到该层，不新开窗口。
- 第三栏随选中项变化；没有选中项时显示当前位置摘要。
- 宽屏不引入 hover-only 的操作；所有动作仍可点。
- 弹层在宽屏居中，最大宽 640，不贴边。

## 无障碍交互

- 焦点顺序 = 视觉顺序：顶栏 → 内容 → 底栏。
- 列表行合并为一个可聚焦单元，读屏一次读完主文 + 副文 + 状态。
- 选择态给 `stateDescription`（已选中 / 未选中），不要只靠视觉。
- 图标按钮的读屏文案用"动作 + 对象"（"暂停：备份任务"）。
- 200% 字号下所有交互元素仍完整可见、可点。

## 反模式

- 自绘边缘返回区（与系统手势打架）。
- 长按进入选择后，单击仍然打开对象。
- 全选后再点一次直接退出选择态。
- 弹层里再弹对话框。
- 破坏性操作放在第一项。
- 点了没反馈，或者用 toast 代替反馈。
- 用"再按一次返回退出"拦截根返回。

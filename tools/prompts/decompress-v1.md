为 Android 手机设计一款名为「解压」的本地压缩包工具 App 的初版高保真界面。

## 产品定位
一个干净、可靠、无广告的解压工具。核心价值是「选一个压缩包，立刻知道里面是什么，然后安全地解出来」。目标用户是普通手机用户，不是开发者。

## 平台与实现约束
- Android 手机，Material 3（Material You）设计语言，画板按 393 × 852 dp 呈现。
- 后续会用 Jetpack Compose 实现，所以请贴近 Compose 的组件语义：TopAppBar、NavigationBar、Card、FilledTonalButton、LinearProgressIndicator、ModalBottomSheet、ListItem。
- 中文界面，字体使用 Noto Sans SC / Roboto 风格。
- 只用系统图标风格（圆角线性图标），不要用 emoji 当图标。

## 视觉方向
- 专业、克制、可信赖的工具感，不要花哨渐变、不要玻璃拟态、不要紫色 AI 风。
- 浅色主题为主：背景 #F6F7F5，卡片 #FFFFFF，主色用深青绿 #0F6B4F，辅助色用暖橙 #C4622D 只用于警示/加密标记。
- 圆角 16–24dp，阴影很轻，分割线用低对比度。
- 留白充足，信息密度适中；标题层级清楚。

## 需要呈现的 6 个画面
1. 首页
   - 顶部：应用名「解压」，右侧设置入口。
   - 主操作卡：大号「选择压缩包」按钮 + 一句说明「支持 ZIP / RAR / 7Z / TAR / GZ 等格式」。
   - 格式能力用一排小 chip 展示。
   - 下方「最近解压」列表，3 条记录，含文件名、大小、时间、状态（已完成 / 失败）。
2. 压缩包详情
   - 头部：文件名、压缩包大小、格式标签、是否加密。
   - 内容列表：文件夹与文件混排，显示原始大小。
   - 底部固定操作区：目标目录选择 + 主按钮「解压到此处」。
3. 解压进行中
   - 大号环形进度或线性进度，显示百分比。
   - 当前文件名、已解压/总大小、速度、剩余时间。
   - 取消按钮；背景保留详情页的模糊层次感。
4. 批量队列
   - 任务列表：每个任务含文件名、进度条、状态（等待 / 解压中 / 已完成 / 失败）。
   - 顶部统计：进行中 2、等待 3、已完成 8。
   - 支持暂停 / 继续的图标按钮。
5. 密码输入
   - 底部弹出的 ModalBottomSheet。
   - 标题「此压缩包已加密」，密码输入框、显示/隐藏密码、错误提示状态。
   - 主按钮「解锁并解压」。
6. 设置
   - 默认解压位置、同名文件处理策略（覆盖/重命名/跳过）、文件名编码（自动/GBK/UTF-8）、深色模式、关于。

## 交互与状态要求
- 首页要有空状态版本（没有最近记录时）作为画板上的一个补充小样。
- 错误状态要具体：例如「压缩包已损坏，仍可尝试提取部分文件」。
- 明确体现安全提示：解压前显示目标空间是否足够。

## 交付形式
- 一张横向设计画板，6 个手机画面并排，画面下方有中文标签。
- 使用单个 HTML 文件呈现（内联 CSS），保证在浏览器中可直接打开预览。
- 画面要像素级对齐、间距一致，像真实产品截图，不要像线框图。

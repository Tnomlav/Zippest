第三次迭代：参考 ZArchiver 和 RAR for Android 的信息架构与操作习惯，重做这个 Android 解压 App。

上一版是消费者式的「首页大卡片 + 最近文件」，不够像专业解压工具。这一版要以文件浏览器为主界面，同时保持 Material 3 的干净视觉。

## 必须吸收的 ZArchiver / RAR 习惯
1. 打开就是文件浏览，不是欢迎页。顶部显示当前路径，例如「内部存储 / Download」。
2. 顶部右侧：搜索、排序、更多。搜索和排序要真实可用。
3. 文件列表紧凑：文件夹优先，每行 64–68dp，图标 + 文件名 + 次要信息（大小 · 日期）。
4. 长按或点复选框进入多选模式：顶部变成「已选 2 项」，底部动作栏切换为「解压 / 压缩 / 复制 / 移动 / 删除 / 更多」。
5. 未选择时底部常驻工具条：新建压缩包、解压、复制、删除、更多。不要用底部导航 Tab。
6. 点击压缩包进入包内浏览：同样的列表形态，顶部是包内路径面包屑，底部是「解压 / 测试 / 信息」。
7. 解压前弹出设置面板：目标目录、同名策略（覆盖 / 跳过 / 重命名）、文件名编码（自动 / GBK / UTF-8）、密码、预计空间、开始解压。
8. 解压进度用底部抽屉呈现，可展开成任务队列；任务可暂停/继续，显示速度与剩余时间。
9. 设置页：主题、默认编码、同名策略、文件关联、关于。

## 视觉
- 沿用 brand-spec.md：背景 #F6F7F5、卡片 #FFFFFF、主色 #0F6B4F、警示色 #C4622D。
- Material 3 组件与图标，线性 SVG，24dp，1.8px 描边；不要照搬 ZArchiver 的拟物图标。
- 信息密度接近工具软件，但留白、层级和触控仍要现代；触摸目标 ≥ 48dp。
- 浅色 + 深色两套主题，深色模式真实可切换。
- 不要营销文案、不要大卡片 Hero、不要多设备并排。

## 需要实现的交互
1. 文件浏览：点文件夹进入下一级，返回箭头回上一级，路径面包屑同步更新；提供 内部存储 / Download / 素材 / 压缩包 的演示目录。
2. 长按任意文件或点复选框进入多选；选择数量实时更新；取消选择恢复默认工具条。
3. 排序菜单：名称 / 大小 / 日期，点击后列表真实重排；搜索框输入时实时过滤当前目录。
4. 点击 `sample.zip` 进入包内列表；面包屑显示 `sample.zip / images`；可返回外层目录。
5. 点「解压」打开设置面板；选择目标目录与同名策略后点「开始解压」，进入进度抽屉，约 4 秒完成并显示成功。
6. 选中加密包 `assets.rar` 解压时，设置面板要求输入密码；密码少于 4 位显示错误。
7. 任务抽屉可展开/收起，至少 3 条任务，可暂停/继续，进度和统计联动。
8. 设置页可切换深色模式、修改默认编码与同名策略。
9. 所有操作都在同一个 App 视口内完成，不跳转页面、不出现设计稿外壳。
